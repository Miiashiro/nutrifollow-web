# 🍎 NutriFollow

Acompanhamento nutricional em tempo real

O NutriFollow é uma plataforma que conecta pacientes e nutricionistas, permitindo o registro de refeições, acompanhamento de adesão ao plano alimentar e comunicação direta entre as partes — tudo em tempo real.

✨ Funcionalidades
Para pacientes
📅 Registro diário de refeições (café da manhã, lanches, almoço e jantar)
📸 Envio de fotos das refeições com observações
📊 Histórico completo de refeições registradas
💬 Comunicação direta com a nutricionista
🎯 Acompanhamento de metas e constância diária

Para nutricionistas
👥 Painel com visão geral de todos os pacientes ativos
📈 Indicadores de adesão (alta, atenção, baixa)
🔔 Alertas de refeições não registradas
💬 Comentários e feedback direto nas refeições dos pacientes
📊 Relatórios de refeições mais esquecidas e tendências de adesão
